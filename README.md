# Data-Analysis# Task 5: Data Analysis on CSV Files

## Objective
Analyze sales data using Python, Pandas, and Matplotlib.

## Tools Used
- Python
- Pandas
- Matplotlib
- Jupyter Notebook
- VS Code

## Dataset
The dataset contains 40 sales records with the following columns:

- Order_ID
- Date
- Product
- Category
- Region
- Quantity
- Price

## Analysis Performed
- Loaded sales data from a CSV file using Pandas.
- Checked dataset shape, column names, missing values, and summary statistics.
- Created a `Sales` column using Quantity × Price.
- Analyzed total sales by product using `groupby()` and `sum()`.
- Created a bar chart for product-wise sales.
- Performed region-wise and category-wise sales analysis.

## Key Findings
- The dataset contains 40 sales records.
- No missing values were found in the dataset.
- Product-wise sales were calculated and visualized using a bar chart.

## Files
- `sales_data.csv` — Sales dataset
- `sales_data_analysis.ipynb` — Data analysis notebook
- `README.md` — Project documentation

## Outcome
This project demonstrates basic CSV data analysis and visualization using Python.
